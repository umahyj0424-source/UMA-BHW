# 우마무스메 쓰리사이즈 업다운 V3

## 이번 버전 변경점

- `UMA-lovetier-main.zip`의 `images/` 이미지 142장을 사이트에 직접 포함
- 외부 나무위키 이미지 주소보다 사이트 내부 `images/...png`를 우선 사용
- 메인 시작 화면 추가
- 시작 전에 B / W / H 중 하나 선택
- 게임 시작 후 A vs B 이미지 비교
- 정답이면 승자가 다음 도전자와 연속 대결
- 오답이 나오면 해당 런 즉시 종료
- 메인 화면으로 자동 복귀
- 메인 화면에 `이번 기록: N연속 성공` 표시
- 최고 기록도 브라우저에 저장
- 데이터 관리 탭은 그대로 유지

## 데이터

기본 쓰리사이즈 데이터: 139명
- B/W/H 완성: 138명
- 나리타 타이신은 B/W/H 누락으로 기본 게임에서 자동 제외
- 데이터 관리 탭에서 직접 채우면 즉시 게임에 포함

포함 이미지: 142장

## 이미지 우선순위

1. 데이터 관리에서 직접 업로드한 사진
2. 이번 ZIP에 포함한 `images/` 로컬 사진
3. 기존 `local_path`
4. 외부 `image_url`

## 실행

`index.html` 더블클릭으로 실행 가능합니다.
GitHub Pages / Netlify에도 정적 사이트 그대로 올릴 수 있습니다.

## GitHub 업로드

이 V3 폴더 전체를 저장소 루트에 올리면 됩니다.
특히 `images/` 폴더와 `data/default_data.js`가 같이 있어야 기본 사진과 데이터가 표시됩니다.
